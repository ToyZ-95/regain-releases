How to install

Install

  1. Tap Download APK on your Android phone.
  2. Open the downloaded APK. If asked, allow your browser to install unknown apps.
  3. Google Play Protect may say the app is from an unknown developer, because Regain isn't on the Play Store yet. Tap More details → Install anyway.
  4. Press your phone's Home button, choose Regain, then Always.

Update or switch back

  1. Update: download the new APK and install it over the old one. Your favorites and settings stay.
  2. Switch back to your old launcher: Settings → Apps → Default apps → Home app.
  3. Uninstall: switch launchers first, then uninstall Regain like any app.

Verify your download

Every official build is signed with the same certificate. Its SHA-256 fingerprint is:

45:EA:B2:7C:FB:DD:06:B9:F1:5C:FE:87:E4:58:EA:F5:72:9D:28:8F:2A:01:7C:65:72:FD:21:B6:6E:BE:04:19

Check the certificate (Android SDK build-tools):

apksigner verify --print-certs regain.apk

Check the file wasn't corrupted (download the matching .sha256 file from the same release into the same folder):

shasum -a 256 -c regain.apk.sha256

Android also enforces this on its own: an APK signed with any other certificate can't install over Regain.
